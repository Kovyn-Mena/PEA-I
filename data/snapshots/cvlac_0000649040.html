    DESARROLLO DE UNA APLICACIÓN WEB PARA LA SIMULACIÓN DE FENÓMENOS CINEMÁTICOS
    Inicio: Diciembre  2016 Duración 
    Resumen

    La investigación tuvo como propósito desarrollar una Aplicación WEB que permitiera simular los fenómenos cinemáticos:Movimiento rectilineo Uniforme, Movimiento Uniformemente Acelerado y Caída Libre, estudiados en la asignatura de Física I de los Programas de Ingeniería de la Universidad Popular del Cesar, Seccional Aguachica. Para el desarrollo de esta estrategia didáctica (CinemaTIC Simulator), enmarcada dentro de las Tecnologías de la Información y las Comunicaciones, como línea de investigación del Grupo GIDEATIC y del Semillero GANEI, se partió de los distintos modelos físicos o matematización de cada movimiento de la Cinemática, aplicando las distintas etapas de todo proceso de simulación sugeridos por (Banks et al; 1996), así como la utilización de herramientas de diseño y programación como HTML5, CSS3, JavaScript implementando la Framework JQuery, y PHP 7.1 para procesos de servidor bajo entorno Linux con servidor Apache, utilizando el IDE Visual Studio Code.

    Inicio: Diciembre  2016 Duración 
    Resumen

    La investigación tuvo como propósito desarrollar una Aplicación WEB que permitiera simular los fenómenos cinemáticos: Movimiento rectilineo Acelerado, Movimiento Uniformente Acelerado y Caída Libre, estudiados en la asignatura de Física I de los Programas de Ingeniería de la Universidad Popular del Cesar, Seccional Aguachica. Para el desarrollo de esta estrategia didáctica (CinemaTIC Simulator), enmarcada dentro de las Tecnologías de la Información y las Comunicaciones, como línea de investigación del Grupo GIDEATIC y del Semillero GANEI, se partió de los distintos modelos físicos o matematización de cada movimiento de la Cinemática, aplicando las distintas etapas de todo proceso de simulación sugeridos por (Banks et al; 1996), así como la utilización de herramientas de diseño y programación como HTML5, CSS3, JavaScript implementando la Framework JQuery, y PHP 7.1 para procesos de servidor bajo entorno Linux con servidor Apache, utilizando el IDE Visual Studio Code.
